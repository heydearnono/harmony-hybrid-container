# research-log — 调研日志

过程记录区，**只追加，不回头改写**。结论请写进 `docs/`。

## 命名

`YYYY-MM-DD-主题.md`，一天可以多篇。

## 每篇建议包含

- **问题**：这次要回答什么
- **检索路径**：搜了什么、看了哪些页面（贴 URL）
- **原始发现**：摘录关键原文，不要只写自己的转述
- **判断**：哪些可信、哪些存疑、哪些互相矛盾
- **落点**：更新了哪些 `docs/` 文件
- **遗留**：没查清的问题

## 为什么要留日志

鸿蒙的 API 与能力开放范围随版本变化，半年后回看 `docs/` 里的结论，需要知道它当初的依据和时间点，
才能判断是否已经过期。日志就是那个时间戳。
